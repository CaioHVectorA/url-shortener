# URL Shortener - Project with Palmares SDK

## Overview
This project is a simple URL shortener using the Palmares SDK. The application allows users to shorten links, redirect visitors, and provide a basic statistics dashboard.

## MVP 1.0 - Basic Features
### 1. Create a Short URL
- User accesses the application (web)
- User inputs the original URL
- User clicks the "Shorten" button
- The application generates and displays a short URL
- The user can copy the short URL to the clipboard

### 2. Redirection
- User accesses the short URL
- The application redirects to the original URL

## MVP 2.0 - Advanced Features
### 3. List My Short URLs
- User accesses the application (web)
- User clicks the "My URLs" button
- The application displays a list of the user's shortened URLs

### 4. Mini Dashboard with Statistics
- User accesses the application (web)
- User selects a short URL from the list
- The application displays a panel with basic statistics for the URL (e.g., number of accesses)

### 5. Revoke a Short URL
- User accesses the application (web)
- User selects a short URL from the list
- The application displays the mini dashboard with statistics
- User clicks the "Revoke" button
- The short URL is deactivated and can no longer be used for redirection
